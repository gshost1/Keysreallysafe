Touch ID does the rest.

  2. Touch ID.macOS shows which key, which task and for how long. One touch.

A grant is one task, not your key.

Every grant is short-lived and fenced in. When it ends, the agent's access ends with it.

  • One key, one hostChange either and the grant is void.

Your data stays on your Mac

  • Dashboard and API bind to 127.0.0.1 only.
  • No account, no sign-up, no license check.
  • Optional “share to compare” is off by default. Turned on, it sends daily usage totals per tool and public model, never prompts, keys, key or project names, paths or device IDs.

No scraping, no borrowed logins

  • Never opens provider websites, cookies or browser sessions.
  • Never reads other tools' auth files.
  • Claude limits come from Claude Code's own /usage, with no model request.

Secrets stay secret

  • Key values never touch the database, a log, the page or the key-list API.
  • Gateway request bodies never reach the usage catalog.
  • Every read of a secret asks for you. Every time.

Every detail, including the exact analytics schema, is in the source and the privacy page.

Questions

Which tools does it read?

Claude Code, OpenAI Codex CLI and Grok CLI, from the session logs and usage caches they already keep in your home folder. Anything else shows as not tracked with a link to that provider's dashboard.

Does it need my provider passwords?

No. It reads files your tools already wrote and never touches their login or auth files. For the vault you paste an API key once; it comes out only after Touch ID.

Is the dollar figure real?

Tokens are real: they're what your Mac measured. Dollars are an estimate from a published list-price table, hidden until you choose USD. Anything unpriced reads as unknown, not $0.

Is it really free?

Yes. Keysrs is MIT-licensed open source with no trial, license key or paid tier. Versions 0.6 to 0.8 had a 14-day trial; the current version removes it, so updating clears a "trial ended" message. If you bought a license, email support@keysrs.com for a full refund.

What Macs does it run on?

macOS 14 Sonoma or newer on Apple Silicon. The download is Developer ID signed and notarized by Apple. No Intel build yet.

How do I uninstall?

keys autostart --remove removes the login item and its snapshot; keys purge deletes the local catalog and every Keychain item the app created, after Touch ID. Nothing is left behind.
