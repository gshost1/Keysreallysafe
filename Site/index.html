New in 0.14A stdio MCP server with sixteen tools and Touch ID on every write

Agents get access. Never your keys.

Keysrs is an MCP server and a loopback gateway for API keys. Your agent calls scan_project and import_and_wrap; secrets move into the macOS Keychain behind one Touch ID, and the env file is rewritten to http://127.0.0.1:12767/<key> plus a project-scoped ksfc_ token with a 30-day expiry. Off the Mac, the same token works through a relay Worker in your own Cloudflare account. No key value crosses the agent, the transcript or git.

The MCP server

Register once.
Every tool returns names, never values.

keys setup mcp writes a keysrs server entry (keys mcp over stdio) into Claude Code, Codex, Cursor, Droid and Claude Desktop, merging around each config's other entries and leaving a .bak. The entry holds the binary's path, never a secret; --remove undoes all five. Tools answer with variable names, providers and last-4 hints; anything that stores a key, issues a token or calls a provider blocks on Touch ID in the app.

scan_project

Finds the keys, not their values.

Looks through the repo's env files and reports each variable's name, provider, last four characters and whether it's already in your vault.

.env  OPENAI_API_KEY  OpenAI  …d27e  in vault
check_exposure

Tells you what git has seen.

For each env file: gitignored or not, tracked or not, ever committed. A key that was ever committed gets one answer: rotate it.

.env.local  tracked · committed once
            rotate OPENAI_API_KEY
import_and_wrap

One Touch ID, and the repo is clean.

The keys go into the macOS Keychain. The env file gets a local gateway URL and a token for that project, valid 30 days. The original is backed up outside the project.

wrapped 2 keys for project evals
token expires in 30 days

Running containers? The agent asks whether Docker should reach the gateway too. It's off unless you say yes, and the Touch ID prompt names it.

Cloud VMs

Remote agents hold a token.
The key stays on loopback.

A VM, a GitHub Actions runner or a cloud coding session can't reach 127.0.0.1. You deploy the relay Worker into your own Cloudflare account; the Mac dials out wss://<worker>/connect with a relay secret, and the Worker pins that one socket in a Durable Object. keys wrap --relay points the env file's base URL at the Worker. Nothing on the Mac listens on a new port.

  1. Wrap.One Touch ID. Secrets go to the Keychain; the env file gets ksfc_ tokens and https://<worker>/<key> base URLs.
  2. Ship.Copy the file to the VM, the Actions secret or the cloud session. The token is useless without your Mac's gateway: it never authenticates to a provider.
  3. Relay.The Worker frames each request onto the socket and checks nothing. The Mac replays it to 127.0.0.1:12767, where the gateway validates the token and scope, injects the Keychain secret and streams the response back, SSE included.

Grants

Access you can see,
and end in one command.

Mid-task, an agent can ask for a key by name. macOS shows you which key, which host and which project, and nothing happens until you touch the sensor.

A grant is one task, not your key.

Every grant and every project token is fenced in. When it ends, the agent's access ends with it.

  • One project, its keysA token works for the keys it was issued for, nothing else.
  • Expires on its own30 days for a project token; you pick for a task grant. You're told three days before a token runs out.
  • Revoke everythingkeys revoke --all ends every grant and token now. No Touch ID: it only takes access away.
  • Rotation revokesRotating a key ends every grant on it. Locking your Mac ends task grants.

Behind the MCP server

A quiet Mac app
holds the keys.

No window, no Dock icon, no menu bar item unless you want them. It starts when your agent or the keys command needs it, and it is the only thing that ever reads a key.

Tells you when it matters.

A notification when a grant is waiting for Touch ID, a token is about to expire, or an update was installed.

Questions

What does my agent actually see?

Variable names, providers, the last four characters of a key, whether it's in your vault, and a token plus a local gateway URL once you approve. Never a key value: no Keysrs tool returns one.

Which agents work with it?

Any agent that speaks MCP. keys setup mcp registers Keysrs with Claude Code, Codex, Cursor, Droid and Claude Desktop for you.

What if a key was already committed?

check_exposure says so, file by file, and recommends rotating that key at the provider. Wrapping it still takes it out of the repo from then on, but a committed key should be treated as leaked.

What happens when the 30 days are up?

The token stops working and you get a notification about three days before. Ask your agent to set the project up again; it's one Touch ID.

How do I undo it?

keys unwrap puts the original lines back in the env file and revokes the project's tokens, after one Touch ID. Uninstalling offers to do this first.

Where's the window?

Keysrs runs in the background. Open it from Applications or Spotlight, or run keys dashboard, to see your keys, grants, activity and usage. The menu bar item can be turned back on in Settings.

How does a VM get a dummy key?

Run keys wrap on the project's env file with your Worker's URL. Copy that file to the VM. Each call goes Worker, your Mac, provider, with the real key added on your Mac. If your Mac is off, nothing is served: a call waits up to a minute, then gets a retryable 503.

Does the Worker see my keys?

No. It's a pipe you deploy from the repo into your own Cloudflare account; Keysrs hosts none. It holds one relay secret that lets your Mac connect and never has a provider key.

Is the dollar figure real?

Tokens are real: they're what your Mac measured. Dollars are an estimate from a published list-price table. Anything unpriced reads as unknown, not $0.

Is it really free?

Yes. Keysrs is MIT-licensed open source with no trial, license key or paid tier.

How does it update?

By itself, if you leave it on: once a day it checks GitHub for a release, verifies the checksum and signing identity, and installs only when nothing is waiting on you. Turn it off in Settings and use Check for Updates instead.

How do I uninstall?

Run keys purge to delete the local catalog and every Keychain item the app created, after Touch ID, then drag Keysrs to the Trash. Nothing is left behind.
