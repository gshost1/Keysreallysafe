How to keep API keys out of .env files on a Mac

Checked against the sources linked on this page on 2026-09-25.

Why is a .env file risky?

A .env file is plain text. Any program running as you can read it, and so can anything that indexes, syncs or backs up the folder, or a coding agent asked to look around the project. One stray git add . and it is in history.

Where should API keys live on a Mac?

In the macOS Keychain, which stores secrets encrypted and tied to your login. The built-in security command can store a key there and read it back into a single command, which is already better than a file. What it doesn't add is a check that you are the one asking each time.

How do I require Touch ID before a key is used?

Keysrs keeps each key in the Keychain and asks for Touch ID or your login password every time a value comes out: copy, reveal, rotate, delete, or handing it to a command. Every read goes into a per-key audit log. The value never enters its database, its logs or the dashboard.

  • keys env openai OPENAI_API_KEY -- python run.py gives the key to that one process as an environment variable, so it never touches the clipboard or a file.
  • keys copy puts it on the clipboard and clears it after 20 seconds.
  • keys rotate swaps in a new value under the same name.

How do I give a script or agent a key without handing it over?

Give it a grant instead of the key. keys grant asks for Touch ID once, then prints a short-lived token and a local base URL. The script uses the token where it would put the API key, and the local gateway on 127.0.0.1 swaps in the real key for that one provider host. The grant can be limited to HTTP methods, paths, a request count and a time limit, and it ends when the screen locks. The real key never leaves the Keychain and the app. For a program you keep running, keys client issue makes a longer-lived token with the same kind of scope.

This narrows accidental and unauthorized use on your Mac. It is not a wall against a program that can already read your memory. The README spells out the limits.
