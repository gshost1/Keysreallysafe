How Claude Code usage limits work

Checked against the sources linked on this page on 2026-09-25.

What are the Claude Code usage limits?

On a Pro or Max plan, Claude Code runs against two limits at once: a session limit that resets every five hours and a weekly limit across all models. Anthropic's Pro plan page describes both, and says further caps may apply at Anthropic's discretion.

Max 5x gives five times Pro's per-session allowance and Max 20x gives twenty times, with the same five-hour reset and weekly limit (Max plan page).

When does the weekly limit reset?

At a fixed day and time set for your account. It is not tied to when you first use Claude or when you subscribed (Pro plan page).

Do claude.ai and Claude Code share the same limit?

Yes. Chats on claude.ai, Claude Desktop and Claude Code all count against the same allowance (how usage limits work). A long chat in the browser leaves less for the terminal.

Are there separate Opus and Sonnet limits?

There can be. Claude Code can report a session limit, a weekly limit, an Opus limit or a Sonnet limit. The session and weekly limits cover every model, so switching model does not help. An Opus or Sonnet limit covers only that family, so switching with /model lets you keep working (Claude Code error reference).

What happens when you hit a limit?

Claude Code stops sending requests until the reset time it shows. In an interactive session it can wait and carry on after the reset by itself (error reference). Your other options are to wait, buy more usage with /usage-credits on Pro and Max (commands), switch to a Claude Console account billed at API rates, or move up a plan (using Claude Code with Pro or Max).

How do I check my Claude Code usage?

Type /usage in Claude Code. It shows your plan limits and what is counting against them (commands). On the web, Settings › Usage on claude.ai shows the current session with its time remaining and the weekly limits with their reset time (usage limit best practices). Claude Code also warns you as a limit gets close.

Can I see Claude Code limits in the Mac menu bar?

Yes, with Keysrs. It reads the five-hour, weekly and Fable percentages that Claude Code already keeps in ~/.claude.json, and shows each window as percent used and time to reset. It makes no request of its own and never opens Claude's login files. If you want the numbers refreshed while Claude Code is idle, Keep Claude Limits Fresh (off by default) runs Claude Code's own /usage every five minutes with the login it already has. Codex and Grok windows sit alongside.
